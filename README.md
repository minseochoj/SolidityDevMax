# SolidityDevMax

SolidityDevMax is a modular, real-time, transaction-agnostic framework for building scalable, gas-efficient smart contract platforms.

The key benefits of using SolidityDevMax include:

- SolidityDevMax is a modular, real-time,
- transaction-agnostic framework for building scalable,
- gas-efficient smart contract platforms

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityDevMax.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
